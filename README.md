## Editable Spotify embeds
In the Songs page, each song has a **SPOTIFY EMBED URL** field.
1. Open Spotify.
2. Choose a song.
3. Use Share -> Embed track.
4. Copy the embed URL from the embed code.
5. Paste the URL into the field.
6. Click **Use Embed**.

The official Spotify player then loads the selected embed.
