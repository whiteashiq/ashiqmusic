# Ashiq Music

A Spotify-inspired music website built with HTML, CSS and JavaScript.

## Run
Open `index.html` in a modern browser.

## Customize songs
Edit the `songs` array in `script.js`. Each song needs a Spotify track ID.
Example:
`https://open.spotify.com/track/TRACK_ID`

Replace the demo lyrics only with lyrics you are licensed or otherwise permitted to display.

## Files
- index.html
- style.css
- script.js
